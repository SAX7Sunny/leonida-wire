# Leonida Wire

Ein inoffizieller, single-file Release-Tracker — verfolgt News, Karte, Cheats und Tipps bis zum Release am 19.11.2026 und danach als Nachschlagewerk.

**Live:** https://sax7sunny.github.io/leonida-wire/

## Features

- **News** — filterbare Timeline (Bestätigt / Gerücht) mit Live-Countdown bis zum Release
- **Karte** — interaktive SVG-Karte von Leonida mit klickbaren Region-Pins
- **Cheats** — Referenztabellen für Teil V (Codes, Controller-Kombos, Telefonnummern); wird ergänzt, sobald offizielle Cheats bestätigt sind
- **Tipps** — Editionen, Preise, Vorbesteller-Bonus, Multiplayer-Ausblick
- **Notizen** — freier Notizbereich, wird lokal im Browser gespeichert

## Tech

Eine einzelne HTML-Datei, Vanilla JS, kein Build-Schritt, kein Framework. Design im Neon-Look (Bebas Neue, Rajdhani, Space Mono).

## Disclaimer

Inoffizielles Fanprojekt ohne offizielle Verbindung zum Publisher oder Entwicklerstudio. Alle Angaben nach bestem Wissen recherchiert und können sich vor Release noch ändern.
